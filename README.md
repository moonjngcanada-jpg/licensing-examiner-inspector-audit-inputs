# Licensing Examiner and Inspector Audit Inputs

Synthetic benchmark packet for licensing examiners and inspectors. The files are fictional and are designed to test source hierarchy, license eligibility reasoning, inspection compliance, renewal-fee reconciliation, enforcement response triage, source rejection, duplicate-license handling, and CSV-integrity validation.

All names, license IDs, facilities, addresses, rules, and records are fictional. The dataset does not describe real applicants, facilities, agencies, inspections, payments, complaints, enforcement actions, or licensing decisions.
